# Frontend JavaScript Module (Person 2)

## Overview
This directory houses client-side JavaScript logic for dynamic user interactions, AJAX requests, form validation, filter controls, and Chart.js integration.

## Responsibilities
- **main.js**: Core initialization, flash message auto-dismiss, dark theme toggle, mobile menu handlers.
- **dashboard.js**: Dashboard data fetching and UI update handlers.
- **expenses.js**: Dynamic expense search, category filtering, delete confirmation modals, quick add/edit modal actions.
- **charts.js**: Chart.js rendering functions for category pie chart and monthly spending trend line charts.
