# Frontend Module (Person 1)

## Overview
This directory contains all HTML templates and CSS stylesheets for the Expense Tracker web application.

## Responsibilities
- **templates/base.html**: Main layout wrapper with navigation, glassmorphic header, sidebar, and flash alerts.
- **templates/auth/**: Login and Registration views.
- **templates/dashboard/**: Analytics Dashboard view with summary cards, chart containers, and recent transactions.
- **templates/expenses/**: Expense management views (list, add modal/page, edit modal/page).
- **templates/errors/**: Custom 404 and 500 error pages.
- **static/css/**: CSS Design system (`style.css`), dashboard aesthetics (`dashboard.css`), and media queries (`responsive.css`).
